구성: 챕터 표지(NN 챕터) → 섹션마다 제목 화면(아이콘+제목, 대본은 제목 한 줄) → 내용 장(헤더 없음, 한 장 = 한 비트: 블록 하나·항목 하나). 대본은 문단 단위로 장에 나눠 붙음.
반복 장면(data-loop): '생각보다 피곤했다'(지친 고양이 숨쉬기 줌), '1,000m와 60m'(종이비행기 둥둥)
등장 시차: 대본 순서를 따르되 1초 이상 걸리는 요소는 앞 요소 뒤에 0.26초 간격으로 이어 붙여 모든 등장이 4초 안에 끝남(순서 보존). 앱에서 data-edit-delay로 조정 가능.
대본: 원고 S01~S22 본문 그대로. 메모체(S06 첫 줄)와 번호 목록 제목(S08·S12·S13·S15·S17)은 읽을 수 있는 문장으로만 다듬음. S05는 사용자 확인대로 '요구사항을 충족시켜 줄 오픈소스를 찾았다'는 뜻으로 고쳐 씀. 첫 제목 장의 한 줄은 S22에서 따옴. 제목 화면 대본은 제목(+부제) 한 줄.
디자인: 채널 '기본체널' 디자인 시스템 (검정 배경 · 흰 글자 · 마젠타 #d4117d · 슬레이트 링 · Pretendard Variable · k-* 모션). 아이콘은 채널 에셋(Fluent Emoji, MIT).
